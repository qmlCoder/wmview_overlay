# 对齐算法原理（RMSD / MESD）

本插件把**待调节分子**整体搬到**参考分子**上，只做**刚体变换**（旋转 $R$ + 平移 $t$），
不改动键长、键角与构型；误差只在**参与对齐的原子**上统计。

设参考分子参与对齐的原子为 $\mathbf{p}_i$、待调节分子的对应原子为 $\mathbf{q}_i$（$i=1,\dots,N$，按下标一一对应），两种指标的定义是：

$$\mathrm{RMSD}=\sqrt{\frac{1}{N}\sum_{i=1}^{N}\left\lVert \mathbf{p}_i-\mathbf{q}_i\right\rVert^{2}},\qquad
\mathrm{MESD}=\frac{1}{N}\sum_{i=1}^{N}\left\lVert \mathbf{p}_i-\mathbf{q}_i\right\rVert$$

## RMSD：均方根偏差

- **优化目标**：最小二乘 —— 最小化各原子偏差的平方和。
- **特点**：平方会把大偏差放大，所以它会优先“照顾”偏得最远的原子，整体贴合最紧。
- **求解**：有闭式解，本插件用 **Kabsch / Horn 四元数法**一次求出全局最优：
  1. 两组选中原子分别平移到各自的质心；
  2. 求相关矩阵 $R=\sum_i \mathbf{q}_i\mathbf{p}_i^{T}$；
  3. 由 $R$ 构造 4×4 对称阵 $K$，求其**最大特征值对应的特征向量**（即最优旋转的四元数）；
  4. 四元数转旋转矩阵，作用到该分子的**全部**原子，再平移到参考分子的质心。
- 第 3 步本插件用 **Jacobi 旋转**求特征值：幂迭代在对称分子（特征值重根，如苯环）上不收敛。
- **适合**：构型接近、想让整体叠合最齐（也是最常用的叠合指标）。

## MESD：平均绝对距离

- **优化目标**：最小绝对偏差 —— 最小化各原子偏差的绝对值和。
- **特点**：对个别原子的大偏差**不敏感**（鲁棒）。这正是它的价值：有个别原子对不上时，它不会被那一两个原子“带偏”。
  代价是它可能主动让个别原子偏出去很远，看起来不如 RMSD 齐。
- **求解**：没有闭式解，只能迭代。本插件用**逐轴贪心下降**（分别绕 x/y/z 试转 $\pm$ 步长、沿 x/y/z 试平移 $\pm2\times$ 步长，
  步长从 0.1 逐步减半到 $10^{-8}$），并且从**两个起点**各跑一次，取误差更小者：
  1. 原始坐标；
  2. RMSD 最优解（Kabsch 结果）。
- **适合**：分子带柔性链、有离群原子，只要求大部分原子一致。

## 两者对比

| | RMSD | MESD |
| --- | --- | --- |
| 定义 | $\sqrt{\frac{1}{N}\sum \lVert\Delta r\rVert^{2}}$，均方根偏差 | $\frac{1}{N}\sum \lVert\Delta r\rVert$，平均绝对距离 |
| 优化目标 | 最小二乘 | 最小绝对偏差 |
| 求解方式 | Kabsch/Horn 闭式解，一次给出**全局最优** | 无闭式解；逐轴贪心下降 + 双起点取优 |
| 对离群原子 | 敏感（平方放大） | 不敏感（鲁棒） |
| 视觉效果 | 整体贴合最紧 | 大体贴合，个别原子可能偏出去 |
| 适合场景 | 构型接近、要求整体最齐 | 有柔性链/离群原子，只求大体一致 |

## 实测对比

用本插件自带的对照脚本（随机分子 + 随机旋转 0~180° + 整体平移 + 构型变形，约一半用例只取部分原子）：

| 检查项 | 结果 |
| --- | --- |
| RMSD 结果 vs 理论最优（400 组） | **0/400 次不一致**，最大差为浮点噪声量级 |
| MESD“从零开始贪心”卡在更差局部解（400 组） | 43/400 |
| 改成双起点后的 MESD（200 组，对比改动前） | 更差 **0** 次，相同 176 次，更好 24 次 |

结论：RMSD 是精确解，可以直接信任；MESD 由于目标函数的性质，**即使求解器最优，也可能出现个别原子明显偏离**。
如果希望“每个原子都尽量贴合”，请用 RMSD。

## 已知限制

- **对应关系按下标**：参考分子选中的第 i 个原子对齐到该分子选中的第 i 个原子。
  两边选中的原子索引不一致时结果没有意义（插件会在日志里提示），可用「同步」按钮一键统一。
- 不选原子时按**全部原子**依次对应，要求两个文件里的原子顺序一致。
- **不考虑对称等价原子**（例如苯环上 6 个等价氢的互换、甲基的三个氢）：需要用户自己选好对应的原子。
- 刚体叠合只能消除整体的旋转与平移；两个分子**构型本身不同**（例如不同的二面角）时，剩余偏差无法通过叠合消除。
